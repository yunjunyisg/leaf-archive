# 植藏电脑与安卓应用

主站：https://gloriouscarnivorousplants.top。两个应用均以独立窗口访问当前主站，使用已有网站账号及密码；个人档案、照片、管理员角色均由网站服务处理。网站页面及后台更新后，刷新应用即可使用，应用不另建离线档案库。

## 下载与安装

下载页：https://github.com/yunjunyisg/leaf-archive/releases/tag/apps-v1.1.0

- 电脑：下载 `LeafArchive-Windows-x64-1.1.0.exe`，双击选择解压位置，完成后打开文件夹内的 `LeafArchive.exe`。这是自解压便携版。支持 Windows 10/11 的六十四位系统，必须保留解压目录内的其他文件。可将这个程序的快捷方式发送到桌面。
- 安卓：下载 `LeafArchive-Android-1.1.0.apk`，在手机文件管理器中打开安装。支持安卓十及以上，系统网页组件需保持更新。首次安装时按系统提示允许当前下载工具安装此应用。
- 两端均需联网。软件功能跟随当前网站已安装版本；应用安装不会自动部署此前提供的网站服务器更新。

首版作为测试版发布：已完成构建、安卓静态检查和签名验证、电脑访问策略检查，尚未在用户实际电脑和手机上完成完整验收。电脑程序没有商业代码签名证书，系统可能提示未知发布者。

## 支持的功能

- 网站专用账号登录、注册，沿用网站的管理员与普通用户权限。
- 浏览植物、产地地图与分类，上传照片。
- 电脑通过保存窗口导出档案和对比图；安卓通过系统文件保存窗口导出档案及对比图，不需要读取整个手机存储空间。
- 安卓支持照片多选、系统返回、点击“植藏”刷新、“我的”页面中的退出账号与退出应用按钮，以及注销等操作的确认弹窗。
- 备案查询及其他外部链接使用系统浏览器打开，应用不会在自己的窗口内加载外部网站。

尚未配置独立的自动更新服务。网站内容更新不需要重装；应用外壳需要更新时，从本仓库下载后续版本。

## 构建电脑版本

需要较新的运行环境及网络，首次构建会下载官方运行组件。以下命令可在构建机执行：

```bash
cd apps/windows
npm ci
npm test
npm run package
```

输出为 `apps/windows/out/LeafArchive-Windows-x64-1.1.0.zip`。构建脚本只复制该应用的代码与图标到临时目录，不复制仓库其他文件、历史备份或网站数据库。压缩步骤在非 Windows 系统需要 Python，在 Windows 使用系统压缩命令。若需自解压版，额外使用官方压缩工具、自解压模块和许可文件，配置 `LEAF_7ZIP_BINARY`、`LEAF_7ZIP_SFX`、`LEAF_7ZIP_LICENSE` 后运行 `node build-self-extract.mjs`。自解压包内保留对应许可。

## 构建安卓版本

需要完整开发工具、安卓开发包及第三十五版平台和构建工具。发布版本使用独立发布签名，首次生成后必须安全保留私钥及其密码，后续版本使用同一签名才能直接覆盖安装。

```bash
cd apps/android
./gradlew assembleRelease lintRelease
```

开发时无签名配置会输出未签名文件；不能把它当作可直接安装的发布包。发布构建从私有构建环境读取以下配置，不将值写入源码：

```text
LEAF_ANDROID_KEYSTORE=/private/path/leaf-archive-release.p12
LEAF_ANDROID_KEYSTORE_PASSWORD=<provided securely by the build environment>
```

固定密钥别名为 `leafarchive`。发布签名私钥及密码不在仓库、安装包和发布附件中；本次构建环境的私有签名目录为 `/workspace/migration-private/app-signing`。迁移构建环境前，应通过私有渠道备份此目录，不能公开上传。不要清理签名目录后重新生成不同签名并当作原应用的覆盖更新。

安装包位于 `apps/android/app/build/outputs/apk/release/`。发布前使用开发工具检查签名，并在真机验证登录、照片选择、地图、数据导出、操作确认、退出与重启。

## 隐私与设备权限

账号密码只通过 HTTPS 提交给主站，不写在安装包里。网站记录保存在服务器，应用仅使用系统提供的网页会话存储；注销网站账号由服务器执行。安卓不申请通讯录、定位、相机或整个存储空间的权限，选择照片和保存文件通过系统窗口授权。不会把会话文件纳入系统备份。

## 我的页面与网站升级

双端可进入“我的”，设置云端显示用户名和头像，查看自己的购入总额、科属分类，并退出账号或退出软件。手机不再显示原生顶部操作栏。普通浏览器不会显示软件退出按钮。显示用户名用于展示，原登录账号保持稳定。

此版本依赖网站安装对应更新包；仅安装新版软件不会升级服务器接口。步骤见 [用户页面更新说明](../docs/profile-update.md)。原有程序、头像和网站签名私钥的隐私规则保持不变。
