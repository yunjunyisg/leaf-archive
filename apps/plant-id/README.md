# 识植助手：独立网页版

由用户提供的 `plant-id-agent-1.0.0.zip` 改编。原包是 DeepSeek Harness 的智能体预设，不能直接作为网页运行；此目录将其植物观察、候选排序、主观概率、区分方法与补充提问规则接到真实视觉接口。原预设留在 `source-preset/` 供追溯，不安装其中的插件，也不执行其中的安装说明；原包的自检记录不代表本项目完成了相同测试。

## 两个应用

| 项目 | 植藏 | 识植助手 |
|---|---|---|
| 入口 | `https://gloriouscarnivorousplants.top/` | `https://gloriouscarnivorousplants.top/plant-id/` |
| 服务 | 现有植藏服务，端口 3100 | 新服务，端口 3110 |
| 数据 | 原有数据库和照片 | `/var/lib/plant-id/plant-id.sqlite` |
| 账号 | 原植藏账号 | 单独注册，不共享登录 |

应用选择页为 `/plant-id/apps`。新应用不导入植藏账号或档案，不调用植藏的植物接口；退出其中一个不会退出另一个。同域名不同路径用于产品与服务隔离，不是两个浏览器来源。若以后需要浏览器来源级隔离，可另配子域名、证书与应用来源。

## 视觉服务

默认使用智谱中国内地接口 `https://open.bigmodel.cn/api/paas/v4/chat/completions` 与 `glm-4.6v-flash`，通过图像内容直接输入模型。公开参考图另由服务器查询 iNaturalist。可改用 `glm-4.6v`／`glm-4.6v-flashx`；权限、费用和可用额度以平台控制台为准。

可选阿里云百炼北京地域的 `qwen3-vl-plus`。配置 `PLANT_ID_PROVIDER=dashscope`，清除旧的 `PLANT_ID_BASE_URL` 或换成百炼北京接口，并使用对应地域的密钥。接口地址仅允许所选平台的中国内地官方地址，不支持任意转发地址；切换平台时不要复用其他平台的密钥。

- [智谱视觉模型文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)
- [百炼视觉模型文档](https://help.aliyun.com/zh/model-studio/qwen-vl-compatible-with-openai)

没有配置密钥时，页面明确显示未开通，识别返回服务未配置，不展示假结果。API 密钥只存在服务器环境或 `/etc/plant-id.env`，不提交仓库、不返回网页。不要把真实密钥贴进聊天；已发送的密钥应撤销后重新生成。

## 功能和数据

- 照片或文字识别；最多四个候选，给出支持依据、区分方法和补拍问题。
- 概率与“其他可能”合计 100%，注明是未经统计校准的主观估计。不能确认到种时保留属／科层级。
- 可保留本轮照片并补充文字继续识别；服务端仅向模型补充当前账号该记录的上一轮结果。旧观察是历史参考，不冒充新图片。
- 原图单张不超过 20 MiB，每轮最多三张；浏览器在本机创建最长边 2048 像素的 JPEG 识别副本，不改用户设备原图。接口单张副本最多 5 MiB，合计最多 10 MiB。
- 本站不保存照片文件；只保存个人描述、识别结果与时间。重新打开历史记录没有旧照片，需要重新看图时须再次选择。删除历史仅删除当前账号的对应记录。
- 页面明确征得本轮向已配置模型平台发送资料的同意。模型提供商对数据的处理仍以其服务条款为准。
- 新应用不提供原预设中的文件搜索、网页检索等宿主工具，不声称已联网核对植物名录。

## 运行与测试

使用 Node.js 24 自带 SQLite 和标准库，没有额外运行依赖。

```bash
cd apps/plant-id
PLANT_ID_ORIGIN=http://127.0.0.1:3110 \
PLANT_ID_DATA_DIR=../../.local-data/plant-id \
node server.mjs
```

无密钥可打开页面和注册，但不能实际识别。实际密钥请使用受保护的环境配置，不放进命令历史。

```bash
npm test --prefix apps/plant-id
```

从仓库根目录运行上述测试。生产安装见 [独立应用安装说明](../../docs/plant-id-web.md)。

## 使用限额与内存

网站取消每日调用次数限制。视觉服务的用量、费用及并发上限由服务商决定，本站同时最多处理 2 次识别。单轮最多 90 秒，响应最大 128 KiB。

每个账号保留最近 10 条植物识别结果，同一会话中的每轮结果单独计数。升级首次启动及保存新结果时会删除超出的旧结果和已空的会话。OCR 与无法整理成候选卡片的原文仅在当次页面显示。

候选参考图按拉丁学名和已知层级查找 iNaturalist 的公开观察，仅向图源查询学名及公开分类编号。页面标注图中物种、作者、许可和原始观察。属或科的参考图可能来自该分类下的具体物种；图源暂不可用时，仍可查看识别结果。


识别使用远端模型，不在这台 2GB 服务器加载模型权重。独立服务设置堆上限及 320 MiB 的服务内存上限，不改动植藏的内存配置。不代表已在目标服务器测得具体内存占用；并发峰值仍应在安装后监控。

配置项见 `.env.example`。密钥配置脚本保留其他设置，但会选择智谱和默认视觉模型。服务日志不记录用户照片、描述、识别结果或密钥。
