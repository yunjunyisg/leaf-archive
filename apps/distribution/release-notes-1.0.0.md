- 电脑：下载 `LeafArchive-Windows-x64-1.0.0.exe`，双击选择解压位置，完成后打开文件夹里的 `LeafArchive.exe`。这是自解压便携版，适用于 Windows 10/11 六十四位系统。

- 支持照片上传、产地地图和账号权限；安卓支持系统照片选择、文件保存及操作确认。
