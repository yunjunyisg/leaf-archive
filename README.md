# 植藏 · 私人植物档案

中文植物收藏记录网站，支持检索、科属分类树、照片导入、植物档案与养护日志。

线上网站：https://leaf-archive-oct03.giving-rook-4847.chatgpt.site （所有用户可打开；个人档案需要登录）

## 功能

- 中文名、学名、收藏编号、来源编号、购入来源、价格与日期
- 产地、个体信息、简介、摆放位置、养护需求及备注
- 多张照片导入，卡片与列表视图，关键词检索与筛选
- 按日期排序的生长时间线，支持补录文字、多张照片和拍摄日期
- 选择两张生长照片生成 PNG 对比图，标注日期、收藏编号和间隔天数
- 养护日期、来源汇总与 JSON 档案导出
- Cloudflare D1 保存档案，R2 保存上传图片；按用户隔离数据

## 本地预览

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run build
npx wrangler d1 execute DB --local --file drizzle/0000_harsh_ben_parker.sql
npm run dev
```

打开 Wrangler 输出的本地地址可浏览示例档案。保存个人档案的 API 需要认证用户身份：生产网站由 Sites 注入可信的 `oai-authenticated-user-id` 请求头。本地接口调试可以手动设置此请求头；自行部署时需要通过可信认证层设置，并过滤客户端伪造的身份头。

## 部署说明

网站继续由 Sites 托管。此仓库保存源码；后续标识修改同时同步到 GitHub 和原有 Sites 线上网站。GitHub 本身没有自动部署工作流，发布仍通过 Sites 完成。`.openai/hosting.json` 保留逻辑存储绑定，不包含原网站标识；`wrangler.jsonc` 中数据库标识用于本地预览，自行部署时需配置自己的 D1、R2 和认证层。

个人植物记录与上传照片的本次备份位于 `backups/personal/`，仅应保存在私有仓库。仓库不包含运行凭据或本地测试数据。示例照片及其署名、来源和许可信息见 `public/credits.json`；请遵守各照片对应的许可。

## 生长记录与对比图

打开植物档案，在“生长时间线”中选择日期、类型，填写文字或导入最多 6 张照片后保存。记录可以按日期升序或降序显示，旧记录保持兼容。已有档案照片的拍摄日期可在“编辑档案”中补填。

在“生长对比图”中选择两张不同照片，点击生成并下载 PNG。带日期的照片会按先后排列并计算间隔；无日期照片会明确标注。对比图在浏览器内生成，不会新增云端图片。

## 桌面快捷方式

网站侧栏的“添加到桌面”提供安装入口与设备操作说明，使用指定植物图标。Android Chrome 可安装或添加到主屏幕，iPhone/iPad Safari 使用分享菜单添加到主屏幕，电脑 Chrome/Edge 可安装独立窗口。实际安装需要在用户设备上完成。

Windows 可下载 `/downloads/leaf-archive-shortcuts.zip`，解压后运行“安装到桌面.cmd”。脚本只在当前用户目录保存图标、在桌面创建指向原网站的快捷方式，不需要管理员权限；源文件位于 `desktop/`。其他系统使用浏览器安装入口。

快捷方式继续使用现有登录和云端数据，查看与保存档案需要联网。Service Worker 仅保存通用离线说明页，不缓存个人档案或照片。网站未接入 AI 生图 API。

## 多设备与多窗口同步

手机、电脑浏览器和桌面快捷方式访问同一网站，登录同一个账号后，共用云端植物档案、照片和生长记录。前台窗口每 15 秒读取最新档案，切回窗口或重新联网时立即读取；同一浏览器中的多个窗口通过通知立即同步。不同账号的档案继续隔离。

编辑表单和未提交的生长记录不会被自动刷新清空。保存与删除校验当前档案版本，其他设备已更新时会提示重新打开，避免旧内容覆盖新记录。旧档案首次保存时自动补上版本，无需数据迁移。断网时不会伪装保存成功，恢复连接后自动重试读取。

运行 `npm test` 验证跨入口读取、账号隔离、并发修改保护与自动刷新行为。

## 微信登录与独立账号

网站开放访问登录页，个人档案与照片仍由服务端按账号隔离。支持微信开放平台网站应用扫码登录（`snsapi_login`），以及微信内公众号网页授权（`snsapi_userinfo`）。新微信账号独立保存数据，收藏编号可与其他账号重复；同一微信账号在多个设备使用同一份档案。

微信实际登录需要项目所有者开通对应权限，并在微信后台登记/校验回调域名。按 `.env.example` 的变量名，在托管平台服务端运行环境设置 AppID、AppSecret 和完整 HTTPS 回调地址。AppSecret 必须作为密钥存储，不放到网页、GitHub 或聊天中。尚未配置时，前端明确显示“微信登录暂未开放”，不会模拟登录。

- `WECHAT_WEB_APP_ID` / `WECHAT_WEB_APP_SECRET`：开放平台网站应用。
- `WECHAT_MP_APP_ID` / `WECHAT_MP_APP_SECRET`：公众号网页授权；用户须在微信中打开。
- `WECHAT_REDIRECT_URI`：当前网站域名下的 `/auth/wechat/callback` 完整地址，与微信后台登记保持一致。
- `TRUST_SITES_IDENTITY=true`：仅在原 Sites 托管中启用可信身份头，保留“原网站账号登录”及原拥有者数据。其他托管环境默认忽略此头，不能把客户端自报的用户 ID 当作身份。

微信授权 state 与当前浏览器绑定，10 分钟有效且单次使用。会话使用 Secure/HttpOnly/SameSite=Lax Cookie，数据库仅保存令牌摘要，30 天过期，退出即撤销。两个微信应用同属开放平台且返回相同 UnionID 时可共用账号；没有 UnionID 时按各应用 OpenID 隔离，既有账号冲突不自动合并。原拥有者数据不会自动迁移给新微信账号。

数据库新增身份、会话和授权状态表，由 Drizzle 迁移创建。`npm test` 使用模拟微信响应验证完整授权流程、会话撤销、跨账号读写与照片隔离；真实微信登录还需完成平台配置后联调。开放登录页不等于已解决中国大陆网络可达性，托管迁移仍需单独完成。

发布包使用 `npm run package:site` 生成，包含 Worker 构建输出和根目录 `drizzle/` 迁移；修改数据库后不能只打包 `dist/`。

## 独立分类树页面

分类树位于 `/classification`，首页侧栏保留入口，不再内嵌分类树。支持界、门、纲、目、科、族、属、组、系、种、变种、变型，允许跳过未填写的层级。未定种（sp.）与种并列；近缘种 aff.、近似种 cf. 为种下节点。相同分类路径的多个收藏个体会归入同一节点，旧档案按已填写的科、属和学名/名称继续显示。支持搜索完整分类路径、全部展开或收起以及点击查看个体档案。分类树读取当前账号的云端档案；示例档案可单独切换浏览。微信登录接入暂时暂停，页面隐藏微信登录入口，保留原网站账号登录与现有账号隔离。

登录后可在分类树中“添加分类”或“添加下级”，无需先建立收藏个体。种、未定种及种下节点的“参考图”入口可导入或移除 JPG、PNG、WebP；每张最多 8 MB，每个节点的参考图数量不限。导入后点击“保存分类”完成，参考图不混入个体档案照片。分类与参考图通过 `/api/taxa` 存储到当前账号的 D1/R2，支持多设备刷新与版本冲突保护，个人图片只能由所属账号访问。

新增/编辑植物时可填写完整分类信息、基础种名与鉴定类别；未定种可用 `某属 sp. 1` 等名称区分。选择 aff. 或 cf. 后填写对应鉴定名称，变种、变型字段自动隐藏。独立建立的分类节点与植物填写的完整分类路径一致时会合并显示。更新网站时需应用 `drizzle/0002_taxonomy.sql`；迁移只新增分类表，不修改已有植物与照片。

## 状态变更与生长线

每株植物档案提供“变更植物状态”，支持生长中、需关注、休眠中、已赠出、已死亡，可填写变更日期和备注。保存时同步更新当前状态，并在生长时间线自动添加“原状态 → 新状态”事件；通过“编辑档案”修改状态也会自动记录当天的变化。同一状态的重复保存不产生事件。状态与历史记录在一次带版本校验的数据库写入中保存，已有状态历史不会因后续编辑丢失。
