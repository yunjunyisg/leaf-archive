# 分类整理更新：删除范围、加入分支与拖动改上级

主站：https://gloriouscarnivorousplants.top。

## 使用方法

- 删除节点时选择“只删除当前节点”或“同时删除所有子节点”。前者把下级接到原上级，根节点的下级提升为根；直属植物归入原上级，没有上级则进入该体系的未分类列表。后者解除整条分支在当前体系的分类关联。
- 两种删除方式都保留植物档案、照片文件、另一套分类和坐标精度。保留子节点时保留其参考图；被删除节点自身的参考图关联解除。删除或移动最后一个子节点，也会保留原上级。
- 未分类植物点击“重新归类”，直接选择已有分支并确认；每张节点卡片也可点击“加入植物”。可归入任意已有层级，替换当前体系的路径，不重复创建植物或自动新增下级。也保留手动填写入口。
- 在分类树按住节点上的“↔ 拖动”，拖到另一个节点上，绿色提示后松开，就会改变上级归属，子分支和关联植物一起移动。拖到屏幕下方的根节点区域可以提升为根。鼠标和手机触摸均支持；取消可松开到无效区域，电脑也可按退出键。
- 点击拖动把手的键盘操作会打开原节点编辑器，仍可通过编辑上级整理。空白处拖动画布的功能保留。
- 循环归属、非法层级、重名或版本冲突会拒绝整笔操作，不自动合并。只删节点使 aff. / cf. 等失去必要上级时也会停止并提示。刷新后核对再操作。
- 删除和归类弹窗正文独立滚动，底部按钮保持可见；拖动期间云端刷新暂缓重绘画布，结束后显示最新资料。

## 安装

下载[更新包](https://github.com/yunjunyisg/leaf-archive/releases/download/taxonomy-organize-v1.7.0/leaf-archive-taxonomy-organize-v1.7.0.tar.gz)，完整上传到服务器的 `/root/leaf-migration/` 后执行：

```bash
(
set -e
cd /root/leaf-migration
echo "1748666633a979168896772b52f36f9a14f57f578772f238f37f5eb14deed8ad  leaf-archive-taxonomy-organize-v1.7.0.tar.gz" | sha256sum -c -
gzip -t leaf-archive-taxonomy-organize-v1.7.0.tar.gz
UPDATE_DIR=$(mktemp -d /root/leaf-migration/taxonomy-organize-verified.XXXXXX)
tar -xzf leaf-archive-taxonomy-organize-v1.7.0.tar.gz -C "$UPDATE_DIR"
(cd "$UPDATE_DIR" && sha256sum -c SHA256SUMS)
bash "$UPDATE_DIR/deploy/apply-standalone-update.sh"
)
```

本包包含当前独立运行层、编译程序及全部公开资源，复用并校验已安装的全球边界，不导入或替换数据库。保留程序回滚和原有私有照片鉴权。若边界缺失或不一致，安装会在替换前停止。

安装完成后刷新网页，或关闭重开 Windows／安卓软件，无需重新安装软件。请先保存未完成的编辑草稿。

当前工作环境没有服务器执行连接；源码及更新包发布不代表主站已安装。需要在服务器执行以上命令后生效。
