# 全球地区层级更新

主站：https://gloriouscarnivorousplants.top。

## 覆盖与行为

本次从仅美国、澳大利亚的细分边界扩展至 **179 个国家或地区的二级行政区、81 个的三级行政区**。[逐国覆盖和资料年份](map-coverage.md)。全部使用本地快照，浏览地图不需要再向海外下载行政边界。

- 默认缩放顺序：国家（缩放小于四）→省州（四起）→二级地区（七起，有数据时）→三级地区（十起，有数据时）。缩小反向恢复，同一植物分类颜色保持稳定，不残留上一级填色。
- 可在“分区层级”手动锁定国家、省州、二级或三级。国家选择、分区点击与植物档案关联，普通账号和管理员总地图共用。
- 平移和缩放时可按地图中心判断所在国家；仍可使用国家下拉框明确选择。
- 所有具体地名、原始坐标、坐标来源与定位精度保留，不批量重新猜测产地。国家、省州代表点不下推到细区县；城市代表点不推断更细行政区。已有明确区县名称可与实际边界匹配。
- 昆明可显示二级区域，再显示五华区的三级区域；古晋、京都、马瑙斯等也可显示二级分区。各国层级定义不同，不能把所有二级都称作县，也不能保证所有三级都更细或反映最新行政调整。
- 无公开边界的国家或地区保留已收录层级和原始标点，明确提示覆盖缺失。本次不是“全球每个县市乡镇均已完整收录”。
- AU、US 的已有细分数据保持；其他来源为 geoBoundaries gbOpen，上游简化几何原样保留，不删除小分区。每个国家的来源、许可、年份、固定版本及校验值可从地图下方“全球地区覆盖与年份”查阅。

颜色代表当前账号或管理员有权查看的已标注档案涉及地区，不代表物种遍布整个行政区或完整野生分布范围。公开概览边界不作为法定边界或精确采集点依据。

## 安装完整更新

本次地图数据较大，请下载[完整更新包](https://github.com/yunjunyisg/leaf-archive/releases/download/global-map-20261031-v1/leaf-archive-global-map-20261031-v1.tar.gz)，上传到 `/root/leaf-migration/` 后执行：

```bash
install -d -m 700 /root/leaf-migration/global-map-update
tar -xzf /root/leaf-migration/leaf-archive-global-map-20261031-v1.tar.gz -C /root/leaf-migration/global-map-update
bash /root/leaf-migration/global-map-update/deploy/apply-standalone-update.sh
```

包含此前的管理员图片下载、杂交种、分类树编辑与删除。程序、编译模块和全部边界文件会一起更新；安装脚本检查文件校验值并备份程序，检查失败恢复旧程序及边界目录。保留数据库、账号和照片，不导入或覆盖个人数据。

安装完成刷新网页或重新打开 Windows / 安卓软件即可，不需重装软件。请勿只上传单独的页面、接口或少数边界文件。当前环境未配置直接执行目标服务器命令的连接，源码发布与服务器安装需要分开完成。
