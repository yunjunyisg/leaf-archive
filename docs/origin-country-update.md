# 输入坐标后选择国家：保留定位

主站：https://gloriouscarnivorousplants.top。

## 编辑植物产地

以前在位置选择窗口中切换国家会清空位置草稿。本次修改为：

- 搜索或输入经纬度后补选国家，保留完整数值、标点和已有位置精度，不改成国家中心。
- 有有效标点时不因选国家而跳离该位置；直接填写的新坐标会显示对应标点。
- 首次补充国家时保留已填写的下级地区；从已知国家改成另一个国家时，保留坐标，但清除原国家的省州、县市、小地名及旧来源关联，并提示核对。
- 选择同一国家时保留仍然有效的地区与来源信息。
- 零经纬度可正常使用；只填了一半的坐标也不会因选择国家而被脚本清空，补全后才能确认。
- 国家选择使此前尚未完成的查询失效，旧结果不会覆盖当前选择。位置编辑使用独立草稿，取消后不改变原位置及其来源。

明确选择新搜索结果或重新点击具体位置仍会更新坐标；点击国家边界进行国家选择时，已有坐标继续保留。更换国家并不代表系统已验证坐标属于该国，需按真实产地核对。

## 主产地地图

选择国家筛选时，保留当前已搜索的坐标及标点，国家只限制档案筛选，不改写已保存的产地。

空国家选项改为“全部国家 / 地区”；“世界全图”和“清除筛选”仍可明确重置搜索点。

## 安装

下载[坐标保留更新包](https://github.com/yunjunyisg/leaf-archive/releases/download/origin-country-v1.5.2/leaf-archive-origin-country-v1.5.2.tar.gz)，上传到 `/root/leaf-migration/` 后执行：

```bash
install -d -m 700 /root/leaf-migration/origin-country-v1.5.2
tar -xzf /root/leaf-migration/leaf-archive-origin-country-v1.5.2.tar.gz -C /root/leaf-migration/origin-country-v1.5.2
bash /root/leaf-migration/origin-country-v1.5.2/deploy/apply-standalone-update.sh
```

包含当前程序及全部公开资源，复用已安装的全球边界；先校验，失败停止或回滚，保留数据库、用户照片及原有档案。缺少全球边界时先按[全球地图说明](global-map-update.md)安装完整边界。

安装后刷新网页，Windows、安卓软件关闭后重开即可，无需重装软件。开发环境没有目标服务器的执行连接，需在服务器安装后主站才会生效。
