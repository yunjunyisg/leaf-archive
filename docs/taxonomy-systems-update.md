# APG IV / ITIS 双路径分类树

主站：https://gloriouscarnivorousplants.top。

## 两套路径分别保存

分类树顶部可选 APG IV 或 ITIS。同一植物可分别填写两套路径，切换查看或修改其中一套不会覆盖另一套；视图选择保留在地址的 `taxonomy` 参数，刷新后仍可查看所选体系。

新增、编辑植物时，分类区域也可切换体系，未保存的两套输入会一起保留到点击“保存档案”。只需填写实际需要的层级，“显示所有可选层级”可展开其余字段；空层级直接跳过，例如“科 → 种”或“科 → 变型”，不生成“未填写科”等占位节点。下级不能放在同级或更低层级之下。未定种、杂交种、aff. / cf. 保留各自约束。

APG IV 模板提供被子植物及多级演化支、目、科与常用下级字段；ITIS 模板提供界、亚界、次界、总门、门、亚门、次门、纲、亚纲、次纲、总目、目、亚目、次目、总科、科及常用下级字段。这里是供手动整理的层级模板，并非内置完整 APG IV 或 ITIS 名录；部分常用/历史字段作为扩展保留，不代表 APG IV 给每个演化支赋予了正式等级。APG IV 主要适用于被子植物。

旧记录不批量重写：原分类继续在 APG IV 视图中展示，并标明未经自动校对；ITIS 路径初始为空。没有自动翻译、猜测上级或将旧分类认定为已按权威体系校对。请按实际植物核对后编辑。

## 中英文与重复检查

每个填写的层级都有“中文名称”和“英文 / 拉丁名称”，至少填一项。树节点同时显示已填写的两种名称。

同一账号、同一体系、相同层级，任一已记录名称匹配时视为同一节点；检查会规范化大小写、空白和兼容字符。跨体系可以保留同名节点，其他账号互不影响。新增重复节点被拒绝，不能通过改放到另一上级重复创建。多株植物可直接复用同一路径。物种名称建议填完整学名，以区分不同属的相同种加词。

已有节点缺少中文或英文名称时，可在档案里直接补全并保存，名称作为该节点的共用资料复用；修改已有的非空名称、层级或上级时，在分类树点击“编辑分类”：保存时原子更新该套路径中的下级分类及关联植物。另一套路径、照片、产地坐标与位置精度保留；冲突或异常时不部分写入。删除分支仅解除所选体系的分类关联，不删植物和照片。当前所选体系的路径为空时，植物显示在该体系的未分类列表；另一套路径不变。

重复依据已保存名称；未记录过的中英文别名不会被自动翻译或猜测为同一分类。旧数据中的差异不会在安装时自动合并。

## 直接使用我的收藏照片

在种级及以下节点的参考图窗口中点击“从我的收藏选图”。优先显示当前体系、当前分类所对应的个人植物照片，也包括这些植物的生长记录照片；可取消分类筛选查看全部个人收藏。

勾选后点击“使用所选照片”，再“保存分类”。引用原图片地址，不重新上传、不新增图片对象；原档案照片保留。可以点击图片放大预览，取消选图不改动原草稿。只有当前账号的收藏可供选择；服务端仍检查私有图片归属。

## 圆角分支画布

依照参考图，节点显示为圆角卡片，由连线连接上下级；悬停有轻微抬起和阴影。标题可折叠/展开，保留编辑、删除、下级与参考图入口。

支持鼠标拖动画布空白处、手机横向/纵向滑动，提供缩小、放大、适应画布和重置视图。不会自动移动节点或根据拖动改变分类关系；没有持续晃动动画，系统要求减少动态效果时关闭交互动画。

## 安装

下载[更新包](https://github.com/yunjunyisg/leaf-archive/releases/download/taxonomy-systems-v1.6.0/leaf-archive-taxonomy-systems-v1.6.0.tar.gz)，完整上传到 `/root/leaf-migration/` 后执行整段命令：

```bash
(
set -e
cd /root/leaf-migration
echo "3b92d4530db468613fff1f05fb565b0ff7255fd6d026333f34b6b0dcfebb384b  leaf-archive-taxonomy-systems-v1.6.0.tar.gz" | sha256sum -c -
gzip -t leaf-archive-taxonomy-systems-v1.6.0.tar.gz
UPDATE_DIR=$(mktemp -d /root/leaf-migration/taxonomy-systems-verified.XXXXXX)
tar -xzf leaf-archive-taxonomy-systems-v1.6.0.tar.gz -C "$UPDATE_DIR"
(cd "$UPDATE_DIR" && sha256sum -c SHA256SUMS)
bash "$UPDATE_DIR/deploy/apply-standalone-update.sh"
)
```

包含当前程序和完整公开资源，复用并校验已有全球边界；不导入或替换数据库、不批量迁移旧分类，保留账号、档案及私有照片。安装后刷新所有已打开页面，Windows、安卓软件关闭再重开即可，无需重装。安装了本包后编辑的双路径仍保存在原有档案 JSON 中，更新前的旧程序不理解新增字段，不应回退旧程序后再编辑这些档案。

当前环境没有服务器执行连接，发布源码与附件不代表主站已安装。
