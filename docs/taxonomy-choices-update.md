# 分类层级已用名称选择

主站：https://gloriouscarnivorousplants.top。

## 使用方式

新增或编辑植物时，界、门、纲、目、科、族、属、组、系、种及种下层级均支持本账号已保存名称的选择。

- 输入部分名称自动筛选，支持中文片段及拉丁名称的大小写不敏感匹配。
- 点击输入框下的“已用选项”，直接从列表点选，每个层级填入一个名称；当前值有勾选标记。
- 使用方向键选择、回车确认，Esc 先关闭选项，Tab 可继续填写下一项。
- 支持自由输入新名称；保存植物或分类后，该名称会成为后续可选项。
- 分类树“添加分类”“编辑分类”的名称框也支持当前层级的名称选择。
- 杂交种、未定种、种、变种、变型、aff. 与 cf. 分别读取对应层级的名称。选择一个层级不会改动其他层级。
- 选项较多时分批显示，可点“显示更多”；手机下方空间不足时向上展开。

收藏、分类树、产地地图三页使用相同功能。网页和软件共用，无需重装 Windows 或安卓软件。

## 名称保留范围

选项来自当前账号**已保存的植物档案和手动分类**，从云端读取，因此刷新或换设备后仍可使用。未保存草稿不会加入。示例档案和其他账号不会加入个人选项。

这不是独立永久历史字典。分类改名、删除，或植物删除、解除分类后，若其他已保存数据也不再使用旧名称，旧名会退出选项，避免纠错后继续推荐错字。账号注销时这些数据仍按既有规则删除，不额外保留名称历史。

不添加数据库表或改写旧档案，不自动批量改名、改变上级分类或重分类。保留此前的新增编辑修复、低内存和地图优化。

## 安装

下载[分类选项更新包](https://github.com/yunjunyisg/leaf-archive/releases/download/taxonomy-choices-v1.5.0/leaf-archive-taxonomy-choices-v1.5.0.tar.gz)，上传到 `/root/leaf-migration/` 后执行：

```bash
install -d -m 700 /root/leaf-migration/taxonomy-choices-v1.5.0
tar -xzf /root/leaf-migration/leaf-archive-taxonomy-choices-v1.5.0.tar.gz -C /root/leaf-migration/taxonomy-choices-v1.5.0
bash /root/leaf-migration/taxonomy-choices-v1.5.0/deploy/apply-standalone-update.sh
```

包含当前完整程序和公开资源，复用已安装的全球边界。安装前校验全部程序、资源和边界，失败会停止或回滚；不覆盖用户数据库或照片。缺少全球边界时先按[全球地图说明](global-map-update.md)安装完整边界。

服务器安装后刷新网页或重开软件生效。开发环境未配置目标服务器的执行连接，源码同步与服务器安装是两个步骤。

## 验证

九十六项自动测试通过，涵盖每个分类层级、片段筛选、去重、不同种级类别隔离、手动分类来源及后台刷新兼容性。

真实 Chromium 浏览器中，对收藏、分类树和产地地图分别完成桌面网页及安卓 WebView 页面标识与手机尺寸检查：输入筛选、直接点选、回车不误提交、保存刷新后再次选择、分类树名称选择均通过。另一账号仅出现自己的名称；手机列表在弹窗内可见，不被底部按钮遮挡。没有脚本异常。
