## 保存约定

- `plant-0.webp` 至 `plant-15.webp`：当前全部开场图标，编号与网站使用的文件一致。
- 本目录用于集中收藏和下载；网站实际加载文件位于 [`public/welcome/`](../public/welcome/)。两处图片内容相同。
- 后续新增或修改植物标识图时，同时更新本目录、网站使用文件及本页预览。
